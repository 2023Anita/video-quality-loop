# 每一帧，都值得再看一遍

2026-10-26。主题：video-quality-loop Skill 介绍。面向希望提升视频完成度的创作者。

概念：银白与暖金色的空间光环从开放旋转转为质量闭环，表达反复审视、收敛与打磨。原创程序动态图形，非实拍或真实软件录屏。未做外部获奖作品对比。

交付规格：1920×1080，16:9，24fps，42 秒，H.264 / AAC。画面保持宽安全边距。音乐为本地程序合成的原创氛围音乐；普通话旁白由 macOS Tingting 语音合成。

| 时间 | 内容 | 画面与声音 |
| --- | --- | --- |
| 00–06 | 每一帧，都值得再看一遍 | 巨幅英文衬线字、环形光带掠过，低频进入 |
| 06–13 | 介绍 Skill 与四步闭环 | 无衬线产品名，银金旋转光环 |
| 13–20 | 十二个质量维度 | 编辑式矩阵逐项出现，旁白解释检查范围 |
| 20–27 | 检查实际成片与时间码 | 自制概念检查窗口，扫描光线、定位说明 |
| 27–35 | 制作、检查、修复、复验 | 四个节点围绕持续运动的光环，暖金依次强调 |
| 35–42 | 完成之后，再进一步 | 中央片名与调用命令，音乐缓慢淡出 |

## 复现

使用 Pillow 12.3.0、NumPy 2.3.5、FFmpeg 8.0.1 和 macOS 自带字体及语音。运行同目录 render.py 生成画面、音频和 MP4；--contact 仅输出概览图。语音与字体依赖 macOS，其他系统需替换这些资源路径与语音步骤。

文档依据：[Pillow 12.3.0 ImageDraw](https://github.com/python-pillow/pillow/blob/12.3.0/docs/reference/ImageDraw.rst)。
