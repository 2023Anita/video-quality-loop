# 视频高完成度制作与自审闭环

把“获奖级视觉目标 → 多维检查 → 实际观看 → 定点修复 → 复验”用于视频制作。质量目标约束制作决策，不覆盖用户指令、事实准确性、授权边界、预算或工具限制。默认由当前主模型执行，不自动委派。

## 1. 确定成片目标

从当前请求和已有素材提取：受众、核心信息、观看平台、时长、画幅、语言、风格、素材来源、交付格式和时间/费用约束。仅询问会改变制作方向的缺失信息；其余作合理假设并简短说明。

先用一句话定义“观众看完应理解、感受或采取什么行动”，再确定故事结构与视听风格。不要把所有视频套入相同的三秒钩子、快切、炫酷转场或结尾号召模板。

对已有视频优先诊断并修改；保留用户明确指定的内容、节奏和品牌要求。

## 2. 使用相符的标杆

优先使用用户提供的参考片；需要外部标杆时，选择与题材、时长、媒介和预算相符的优秀视频，提炼其叙事、镜头、节奏、声音与视觉系统。需要查询获奖作品、当前案例或具体链接时，核实作品与出处，不凭印象编造。

Awwwards、Webby、FWA 可作为视觉完成度的启发，不把网页奖项直接当作视频质量认证。交互网站参考主要用于字体、留白、层级、色彩和运动语言；视频参考用于时间结构与声音。只借鉴原则，不复制标识、镜头或未获许可的素材。

没有可访问的参考片时，使用下面的可观察标准，并明确“未做外部作品对比”；不宣称已匹配具体获奖作品。

## 3. 先设计时间，再制作画面

建立简洁分镜/时间线，记录每段的时间范围、信息任务、画面、屏幕文字、运动、旁白/声音。文字承载量须匹配实际阅读时间；旁白时长按真实语音校准，不能只靠字数估算。

定义最小统一视觉系统：字体层级、边距/安全区、色板、构图原则、运动节奏和声音风格。选择最能检验方案的片段做预览；对短片或轻量改动可直接制作全片，避免流程本身增加无用成本。

按任务选用已可用的制作工具。质量闭环不绑定某个视频引擎；若需要引擎专用 Skill，仅按实际需要读取。未明确授权的付费生成、上传、发布或外部发送，不因质量迭代而获得授权。

## 4. 成片检查维度

每项标记为“通过 / 待修复 / 未验证 / 不适用”，记录证据。不要用总分平均掩盖单项严重缺陷。

| 维度 | 可观察的验收标准 |
| --- | --- |
| 叙事与信息 | 核心信息明确；每段推进理解或情绪；铺垫与结尾呼应；无无效重复、事实错误或无依据的承诺。 |
| 字体与字幕 | 字形稳定、层级一致、无溢出截断；实际播放时可读；字幕与语音同步；中英文断行自然，关键信息不被遮挡。 |
| 留白与构图 | 主体明确；边距与安全区稳定；画面密度匹配信息量；没有意外相切、拥挤或干扰阅读的背景。 |
| 视觉层级 | 每个镜头的首要关注点清楚；文字、主体、强调色与运动共同引导注意力，不互相争抢。 |
| 色彩与光影 | 色板和曝光连贯；文字与背景分离；无意外色偏、过曝、压暗细节或廉价滤镜堆叠。 |
| 运动与连续性 | 运动服务信息；速度、缓动、停留和运动模糊合理；无抖动、穿帮、闪烁、突跳或生成素材的身份/几何漂移。 |
| 剪辑与节奏 | 镜头长度匹配内容、阅读和情绪；转场有动机；无黑帧、残帧、意外停顿或过密快切；关键观点有理解时间。 |
| 微动效与细节 | 标注、数字、图标、光标等细节反馈准确；强调适量；没有无意义的持续晃动。交互视频另验悬停、点击和状态反馈；普通视频不强加交互。 |
| 声音 | 旁白清楚；音乐与音效支持情绪；无削波、突兀切音、明显底噪或掩盖语音；音画同步；有声交付须实际听审。静音视频标记声音不适用。 |
| 平台与画幅适配 | 在目标尺寸和设备观看条件下可读；主体、字幕、平台控件安全区合理；多画幅分别重构与检查，不能仅拉伸或机械裁切。 |
| 原创性与一致性 | 视觉概念与题材相符；有贯穿全片的识别线索；素材和镜头风格协调；原创性不以牺牲清晰度为代价。 |
| 导出与完整性 | 实际文件可播放；分辨率、画幅、帧率、时长、编码及音轨符合交付要求；无缺失媒体、水印占位、意外静音或未替换文案。 |

平台规格和响度等数值依交付目标确定，不把某个固定值设为所有视频的标准。技术元数据只能证明文件规格，不能代替视听检查。

## 5. 对实际成片执行自审闭环

1. 渲染可检查的预览或成片；验证文件存在、可解码并读取实际规格。
2. 以正常速度观看全片，有声作品同步听审；再检查首尾、关键画面、字幕密集段和所有转场。工具仅支持抽帧时，记录覆盖范围，运动和声音保留“未验证”，不能把抽帧当成完整观看。
3. 按检查表记录具体缺陷：`时间码/区间 → 现象 → 对观众的影响 → 最小修复 → 复验结果`。审美判断说明理由，例如“标题尚未读完即切走”，避免只有“更高级”这类空泛评价。
4. 先修事实错误、播放故障、信息不可读和声音问题，再修层级、连续性、节奏与装饰细节。修复根因，不为局部问题重做全片。
5. 重新渲染，复验修改区间及相邻镜头；最终交付前再检查完整最新导出，防止只验旧预览或局部片段。

默认最多三轮修复—复验；用户给出迭代预算时服从该预算。若同类问题连续两轮无改善，或下一轮需要新增费用、外部授权、关键素材或能力，停止对应修复，交付当前可审查结果并列明阻碍与下一步。不得为了满足“无改进空间”而无限生成或虚报通过。

完成条件：最新成片已完成相应视听检查，所有适用维度通过，已知可观察缺陷均已解决，剩余优化属于偏好或超出约定范围。存在未验证项或待修复项时，明确标记部分完成，不宣称全部通过。获奖水准是创作目标，不是获奖保证或客观认证。

## 6. 交付

优先呈现可播放的视频或预览，并提供实际文件链接；按用户要求附源文件。简短报告实际规格、主要改进、检查覆盖、迭代轮次和剩余限制。没有实际渲染时只交付已完成的脚本/分镜/工程，并明确尚未完成成片验收。

```text
受众与目标：[观众及看完后的理解/感受/行动]
平台、画幅、时长：[要求；未知项作合理假设]
风格与参考：[参考片或视觉方向]
交付与预算：[文件格式、源文件、迭代时间/费用约束]

目标：在约定范围内达到高完成度、风格鲜明且视听连贯的成片质量。
检查：叙事、字体字幕、留白构图、视觉层级、色彩光影、运动连续性、
剪辑节奏、微动效、声音、平台画幅适配、原创性、导出完整性。
闭环：制作 → 检查实际成片 → 记录时间码缺陷 → 定点修复 → 重新渲染复验。
验收：适用项均通过；未验证项如实说明；遵守预算与迭代上限，
不得用“获奖级”口号代替视听证据，不得自动付费、上传或发布。
```
